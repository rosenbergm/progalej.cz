# Co jsme dnes dělali

## Úlohy z hodiny

1. Přidejte nového řidiče Petra Horáka, narozeného 1990-05-14, s číslem řidičáku 2001-1234-56.
2. Přidejte dvě nová vozidla najednou: dodávku 3B2 11-22 (nosnost 4800) a kamion 7C5 99-01 (nosnost 13000).
3. (\*) Zkopírujte všechny jízdy Nováka z ledna 2014 do nové jízdy se stejnými hodnotami, ale datem posunutým o rok (2015-01-\*).
4. Řidič Novotný se ve skutčnosti jmenuje Nový. Opravte jméno.
5. (\*) Všem dodávkám zvyšte nosnost o 500 kg.
6. Smažte všechny jízdy kratší než 35 km.
7. (\*) Smažte všechny jízdy z března 2014 pro vozidla typu sklápěč.

8. Prohlédněte si plán dotazu bez indexu, pak index vytvořte a porovnejte. Chceme na tomto sloupci index? Proč ano/ne?
   ```sql
   EXPLAIN QUERY PLAN
   SELECT * FROM jizda WHERE datum = '2014-02-15';
   ```
9. Vytvořte složený index pro dotazy, které filtrují podle řidiče a data zároveň.
10. Vytvořte unikátní index pro sloupec SPZ u tabulky vozidel. Poté ověřte, že funguje.
