# Co jsme dnes probrali?

## Šifry a Linux

Vytvořte si pár klíčů:

```bash
gpg --full-generate-key
```

Při tvorbě zvolte defaultní hodnoty pro typ klíče, apod. Vyplňte
svoje jméno a e-mail.

Nyní jste získali pár dvou klíčů -- veřejný a soukromý. Vyexportujte
veřejný klíč pomocí:

```bash
gpg --armor --export <email zadany pri vytvareni> > <login>_pubkey.asc
```

Vložte ho do sdíleného adresáře `/home/shared/<login>`.

Kamarádův klíč naimportujte pomocí

```bash
gpg --import <login kamarada>_pubkey.asc
```

a zkontrolujte, jestli se správně naimportoval

```bash
gpg --list-keys
```

### Šifrování (asymetricky)

Pro to abychom jen zašifrovali, použijeme

```bash
gpg -e -r <email kamarada> <cesta k souboru>
```

Pokud chceme jak zašifrovat, tak podepsat, použijeme

```bash
gpg -se -r <email prijemce> <soubor>
```

Výstup programu dejte do svojí sdílené složky, odkud si ji
kamarád zkopíruje a dešifruje

```bash
gpg -d <soubor>
```

### Šifrování (symetricky)

Zašifrovat pomocí

```bash
gpg -c <soubor>
```

a dešifrovat pomocí

```bash
gpg -d <soubor>
```
